## 📱 Mobile 2FA App in Python (TOTP)

RWB 2FA Mobile UI is a **secure, local-first 2FA (Two-Factor Authentication) application** built in Python for Android using **Pydroid 3**.

This app generates **TOTP (Time-based One-Time Password)** codes and stores all sensitive data **locally on your device**.

No cloud. No tracking. Full control.

---

## 🔒 Key Features

- Encrypted local vault  
- Add / edit / delete accounts  
- Search and sort (A–Z / Z–A)  
- Safe copy of TOTP codes  
- Show / hide secret keys  
- Import / export encrypted backups  
- Duplicate detection  
- Manual lock for extra security  

---

## 🧠 Why This Project

This project demonstrates that Python can be used to build **real-world mobile security tools**, not just scripts or backend services.

It is ideal for:
- Learning how **TOTP authentication** works  
- Understanding **local encryption**  
- Building your own **privacy-focused tools**  
- Exploring **mobile Python development (Pydroid 3)**  

---

## ⚠️ Security Notice

This repository does **NOT include any real secrets or keys**.

Users must create and manage their own authentication data.

## 🚀 Getting Started

1. Install **Pydroid 3** on Android  
2. Download or clone this repository  
3. Run the Python script  
4. Add your 2FA accounts manually
